FULL-STACK PLATFORM

LOVIA

Crowdfunding Platform

Lovia 是一個以創作者募資為核心的全端平台，提供專案瀏覽、 會員註冊登入、募資方案選擇、金流串接與訂單管理等功能。

於 Lovia 募資平台專案中， 負責前後端整合開發與系統架構設計， 包含 RESTful API、 JWT 驗證機制、 Google OAuth 第三方登入、 LINE Pay／ECPay 金流整合， 以及結合 Google Gemini 的 AI 智慧客服功能。 透過 AI 與全端技術整合， 完成募資、訂單與付款流程串接， 打造兼具互動體驗與實用性的募資平台。

PRODUCT GOAL

From Project Discovery To Support

平台目標是讓創作者能建立募資專案，並讓支持者能清楚瀏覽專案內容、 比較贊助方案、完成付款並追蹤訂單狀態。

整體設計重點放在募資流程的連續性：從專案探索、會員登入、 方案選擇、訂單建立到第三方金流付款，每一步都需要讓前後端資料狀態保持一致。

KEY FEATURES

Platform Functions

AUTH

會員系統

支援註冊、登入、JWT 驗證與會員資料管理，讓使用者狀態能安全地在前後端傳遞。

PROJECTS

募資專案

使用者可以瀏覽不同募資專案，查看專案介紹、目標金額、贊助方案與進度。

ORDERS

贊助流程

支援選擇方案、建立訂單、串接付款流程，完成從專案瀏覽到付款的完整流程。

PAYMENT

金流整合

整合 LINE Pay 與 ECPay，處理付款請求、交易狀態與回傳結果。

API

後端 API

以 Node.js 建立 RESTful API，負責會員、專案、訂單與付款相關資料處理。

AI SERVICE

AI 智慧客服

結合 Google Gemini，提供使用者平台操作與募資流程相關的即時問答體驗。
